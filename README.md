# The 21-Day Gut Reset — site

Static export, ready for GitHub Pages.

## Deploy
1. Create a GitHub repo (or use an existing one).
2. Upload these files to the repo root (or a `docs/` folder).
3. In repo Settings → Pages, set the source to the branch/folder you used.
4. Your sales page will be live at the Pages URL; `thank-you.html` is your payment gateway's redirect page.

## Files
- `index.html` — the sales page (home page)
- `thank-you.html` — post-purchase thank-you / download page

## Before going live
- `index.html` already links to your payment URL (https://rzp.io/rzp/Nmod2sJ).
- Replace `DOWNLOAD_EBOOK_URL_HERE` in `thank-you.html` with your real PDF download link, and set this page as your payment gateway's post-purchase redirect.
